# Information Security Store Announcement — Texas #341

## Executive Summary  
This announcement (document ID: NRG-ANN-GOLD-0341) addresses important information security measures related to the deployment and management of the product **Nirvana Dock Pro** (product code: NRG-ACC-2001) across all retail locations in the **Texas** region. ## Summary  
The Information Security department issues this announcement to all Texas region stores to reinforce security protocols for the Nirvana Dock Pro devices. The selected 101 units of Nirvana Dock Pro devices will undergo an enhanced security check during the specified period. This process is critical to verify the devices’ firmware versions, network access controls, and endpoint security configurations.

## Controls  
- Physical security of Nirvana Dock Pro units must be maintained at all times, restricting access to authorized personnel only.  
- Firmware and software updates for product code NRG-ACC-2001 are mandatory and must be applied within the week number 30 timeframe.  
- Network traffic to and from Nirvana Dock Pro devices will be monitored for anomalous behavior in compliance with the Information Security policy.  
- Access logs for each device must be retained for a minimum of 90 days and reviewed weekly.  
- Regular audits will be conducted on the sample units (101 devices) to ensure compliance with security standards.  
- Any deviation from the prescribed configuration or unauthorized access attempts must be reported immediately to Information Security.

## Roles and Responsibilities  
- **Store Managers (Texas Region):** Ensure the sample units are accessible for inspection, enforce physical security protocols, and coordinate with security teams for updates.  
- **Information Security Team:** Lead the inspections, monitor security alerts, manage patch deployments, and provide support for incident investigations related to Nirvana Dock Pro devices.  
- **IT Support Staff:** Assist with applying firmware updates and troubleshooting technical issues that arise during the security checks.  
- **Compliance Officers:** Document audit findings and oversee the adherence to Information Security policies across all Texas stores.

## Exceptions and Escalation  
- Exceptions to this announcement’s mandates must be formally requested in writing and approved by the Information Security Director.  
- In the event of a security breach or failure in compliance identified within the sample units, escalation must proceed immediately through the chain of command to the Regional Security Manager and Information Security Director.  
- Temporary operational disruptions caused by security interventions should be reported and mitigated with fallback procedures to minimize retail impact.
