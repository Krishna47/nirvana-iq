# Information Security and Data Classification Policy

## Classification Levels
Public, Internal, Confidential, and Restricted.

## AI Systems
Enterprise AI systems must:
- enforce source-level access controls
- avoid exposing restricted data
- record retrieval and tool usage
- provide citations for policy-based answers
- require human approval before external actions
